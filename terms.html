1. 服务说明

知径是一款本地优先的自主学习工具。应用本身不提供大模型服务；教学内容由你自行配置的第三方模型接口生成。你需要自备 API Key，并遵守对应服务商的条款与计费规则。

2. 使用限制

你不得利用本应用生成、传播违法违规内容，不得侵犯他人权益，不得干扰模型服务商的正常运营。应用面向具备自主学习能力的成年人；未成年人应在监护人指导下使用。

3. AI 生成内容

讲解、题目与评价由模型生成，可能存在错误或偏差，不构成医疗、法律或投资建议。每条回复带有生成内容标识，重要结论请自行核实。

4. 数据与隐私

学习记录保存在本机。发起教学或练习时，必要的对话上下文会发送到你配置的模型服务。详见隐私政策。

5. 免责

因模型服务不可用、网络故障、设备异常或你误删本地数据造成的损失，应用不承担责任。请自行备份重要记录与 API Key。

6. 知识产权

应用代码与界面归开发者所有；模型生成内容的相关权利按服务商条款处理。你可以导出自己的学习记录用于个人用途。

7. 变更与终止

测试版本可能随时调整或停止。停止后已安装版本仍可使用，但不再获得更新。
