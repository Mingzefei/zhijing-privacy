隐私政策

知径 · 本地优先 · 更新日期 2026-10-27

一句话

知径不设账号系统，不收集、不上传你的学习记录。目标、路径、会话、手写草稿都存在这台设备的应用沙箱内。

本地保存了什么

学习目标与自述起点、会话与消息、概念与依赖边、复习安排、模型配置。手写草稿以坐标数据的形式随消息一起保存在本机。除你主动发送外，草稿不会被上传。

什么会离开设备

只有当你发起教学或练习时，必要的对话上下文（目标、最近的问答、概念命题）会发送到你自行配置的模型接口，用于生成回复。服务商如何处理请求，取决于该服务商的隐私政策。知径不经过自有服务器中转。

API Key

你的 API Key 保存在应用私有偏好设置中，仅本应用可读。它不会出现在日志、导出物或对话内容里。

权限

仅申请网络权限（ohos.permission.INTERNET），用于访问你配置的模型接口。不读取通讯录、位置、相册或剪贴板。

AI 生成内容

对话中的讲解、题目和评价由模型生成，可能出错。它们不构成医疗、法律或投资建议。每条回复都带有 AI 标识；重要结论请自行核实。

举报与纠错

如果遇到违法或有害的生成内容，请通过应用内「设置 → 反馈」复制反馈邮箱并发送截图。我们会在合理期限内处理。

未成年人

应用面向具备自主学习能力的用户。未成年人应在监护人指导下使用；涉及付费模型额度时，由监护人管理账号。

发布说明

当前构建用于个人部署与技术验证，模型由使用者自备。面向中国大陆公开上架前，运营方需完成 APP 备案、生成式人工智能服务备案/登记与安全评估，并使用已完成备案的模型服务。
